# Full Stack Product Management System

A full-stack web application built using React.js and Django REST Framework to manage product details. Users can add, view, update, and delete products through a simple and responsive interface.

## Tech Stack

### Frontend
- React.js
- Axios
- HTML
- CSS
- JavaScript

### Backend
- Python
- Django
- Django REST Framework

### Database
- MySQL

## Features

- Add new products
- View all products
- Update product details
- Delete products
- REST API integration
- Responsive user interface

## Project Structure

```
Full-stack-Product_System/
│
├── reactproductsystem/    # React Frontend
└── webserver/             # Django Backend
```

## Installation

### Clone the repository

```bash
git clone https://github.com/kavyaba2005-commit/Full-stack-Product_System.git
```

### Backend Setup

```bash
cd webserver
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend Setup

```bash
cd reactproductsystem
npm install
npm start
```

## API

The React frontend communicates with the Django REST API using Axios.
